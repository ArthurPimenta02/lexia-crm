# Project Context

Before changing this project, read `Agent.MD` and `PLAN.MD` in the repository
root. `Agent.MD` is the current architecture and operations map; `PLAN.MD`
contains prioritized risks and acceptance criteria.

When a change affects routes, database contracts, integrations, environment
variables, metrics, permissions, destructive actions, or deployment, update the
corresponding documentation in the same change. Never add secrets to these
files or to the repository.
